# 飞鸽快传 macOS 客户端

本项目位于 `Project/MacOS/`，与 `Project/Windows/` 客户端共用协议及开发规范；两个平台使用同一 `main` 主线。

Swift 6 / SwiftUI，最低 macOS 13，通过 Swift Package 构建。

```sh
cd Project/MacOS
swift build
swift test
swift run
```

## 使用

启动时先读取设备身份并执行一次真实签名检查；如有系统钥匙串弹窗，请输入 Mac 登录密码并选择“始终允许”。准备完成后才开放设备发现和连接。授权失败可点“重新授权”；应用不读取或保存登录密码。同一次运行中的连接和重连复用已准备好的身份，不再逐次读取钥匙串。

如果只选择单次“允许”，或应用更新、钥匙串重新锁定、系统访问规则改变，macOS 仍可能再次要求授权。系统授权不能由应用缓存密码代替。握手等待签名证明单独保留最多 5 分钟，避免另一台设备还在授权时被旧的 15 秒总期限中断。

1. 首次启动通过“本机设置 → 准备连接”两步引导设置设备名称与接收文件夹；可稍后继续，进度会保留。确认后再准备设备身份并启动网络。应用自动发现局域网中的同版本设备。
2. 选择左侧设备并请求连接，也可手动输入对端 IP 和端口。
3. 对方点一次“同意连接”，即可在同一个会话里聊天、发送图片与文件。
4. 文字 Enter 发送、Shift+Enter 换行；支持系统输入法、文字复制粘贴。图片与文件可选择、拖入输入区；剪贴板中的图片也可在输入区按 ⌘V 粘贴发送。附件卡片可预览图片、PDF、DOCX 正文和常见文本/源码；图片可缩放，文本与 DOCX 预览均为只读并有大小、行数限制。DOCX 只提取正文段落、换行和制表符，不解析复杂排版或运行文档内容。文件卡片可打开文件或在访达显示。
5. 文件传输期间仍可聊天，双方可同时传文件。文字收到对端回执后显示“已送达”。失败的已发送消息可在重新连接该设备后重试。

无产品文件大小上限，支持空文件；实际大小由文件系统和可用磁盘空间决定。图片按原图发送，不压缩。单条文字最多 8 KB UTF-8，长文可作为文件发送。

取消传输会断开连接并清理未完成文件，已完成文件保留。重试文件重新发送，不支持断点续传。一次只连接一台设备；其他设备历史可查看，发送控件只对已连接会话可用。

本地保存最近 1000 条已结束会话消息；重启后未完成消息标记为失败。旧版文件历史从“传输记录”查看。图片预览依赖原始文件仍在本地；不支持的图片格式保留文件卡片。保存或更改接收目录时会清除目录中符合 Feige 专用命名规则的孤立未完成文件，不触碰普通文件或符号链接。暂未提供群聊与离线投递。

会话列表右键可打开、隐藏或删除会话记录；隐藏会话可在偏好设置中恢复。删除前会确认，不删除已接收文件或独立传输记录；活动连接和未完成传输不能删除。新消息或重新连接会恢复隐藏会话。

遇到连接失败时，可从错误提示打开“连接排查”，查看局域网、VPN/TUN、路由器隔离及防火墙检查方法。应用保留原始错误，不会自动修改系统代理、防火墙或路由设置。

关闭主窗口后应用继续运行，点击 Dock 图标可重新显示主窗口；也可通过“文件 → 显示主窗口”（⌘1）打开。最小化窗口会恢复显示，重复打开不会创建多个主窗口。退出应用仍使用 ⌘Q。

## 本地预览包

```sh
./scripts/package-app.sh
```

生成仓库根目录同级 `Release/MacOS/0.3.3/飞鸽快传.app` 与 `Release/MacOS/0.3.3/FeigeMac-0.3.3.zip`。交付输出位置由仓库根目录定位，与从仓库根目录或本目录启动脚本无关。打包前会从 `Project/Ui/Branding/FeigeIconV1/Feige.icns` 安装正式应用图标，再执行签名。默认 ad-hoc 签名，仅供本地预览。正式公证需提供 Developer ID Application 证书和已有公证凭据：

```sh
FEIGE_SIGN_IDENTITY='Developer ID Application: ...' FEIGE_NOTARY_PROFILE='已有凭据名称' ./scripts/package-app.sh
```

两端均需更新到 v3。Windows v3 客户端已完成，已有 Windows↔Mac 基本互通反馈；完整实体双机矩阵、原生界面完整操作、公证及干净机器安装仍待[验收](../Docs/MacOS/AcceptanceChecklist.md)。
