# Windows 1.3.0 发布说明（草稿）

状态：**草稿，尚未打包**。正式打包时复制到 `Release/Windows/1.3.0/`，并补上实际构建号、文件大小与 SHA-256。逐轮实现与验证见 [Windows 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 新功能

- **新手引导与头像**：首次启动可选择 10 个内置头像，或跳过；对方头像只在完整指纹与已认证连接匹配后显示。
- **群成员面板**：在群聊里查看成员、角色与在线状态，可搜索；群主移除成员前需要确认。
- **跨网段**：可在设置中添加其他网段的探测目标，用于路由可达但收不到广播的局域网。
- **未读与通知**：会话列表显示未读数，托盘与系统通知提示新消息。
- **常驻联系人**：标记后自动同意对方连接并在断线后自动重连；文件仍需逐次确认。
- **文件夹与断点续传（协议 v6）**：整个文件夹只确认一次；传输中断后从断点继续。需要对方也支持 v6。
- **离线待发**：对方不在线时，消息和文件先排队，连接后按顺序发送；可取消，超过 7 天转为失败。
- **会话合并**：同一台设备因身份变化分成两段会话时，可右键“合并到其他会话…”。
- **附近设备去重**：已有会话的设备不再在“附近设备”里重复显示。
- **身份保持**：卸载重装或删除资料目录后沿用原身份，对方不会把本机当成新设备。

## 兼容性

- 与 macOS 0.5.0 及以上版本可使用全部功能；与旧版本互通时回退到双方都支持的协议（v3/v4/v5），文件夹与续传不可用。
- 只提供 EXE 安装包，不提供商店版（MSIX）。
