# Windows 1.3.2 发布说明

状态：**待发布**（build 1308）。逐轮实现与验证见 [Windows 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 修复

- **点击表情后崩溃**：在会话中点击“表情”按钮，应用直接退出。现在表情面板可以正常打开和插入。
- **对方离线时弹出错误**：正在对话的设备离线或断开时，页面顶部出现红色“连接已中断”错误条，需要手动关闭。现在只把状态改为“连接已断开”，会话和未完成的消息照常显示断开。

## 兼容性

- 协议版本不变（v6），与 macOS 0.5.0 及以上版本可使用全部功能。
- 只提供 EXE 安装包。

## 交付文件

| 文件 | 用途 |
| --- | --- |
| `FeigeSetup-1.3.2-b1308-x64.exe` | Intel / AMD Windows |
| `FeigeSetup-1.3.2-b1308-arm64.exe` | ARM Windows（含 Apple Silicon 上的 Parallels） |
| 各安装包的 `.exe.json` | 版本、架构、大小、SHA-256、签名状态 |
