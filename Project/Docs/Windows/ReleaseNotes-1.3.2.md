# Windows 1.3.2 发布说明

状态：**已发布**（2026-11-04，build 1308）。公开页面为 [GitHub v1.3.2](https://github.com/jiongboy/FeigeTransfer/releases/tag/v1.3.2)。逐轮实现与验证见 [Windows 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 改进

- **连接请求只需同意一次**：同意后对方自动成为常驻联系人，之后这台设备再连接无需确认，上线时自动连接；可在设置的常驻联系人中移除。接收文件仍需逐次确认。
- **应用内更新更可靠**：局域网更新服务改用公司内网可直达的地址 `10.80.10.188:8080`，原来在二级路由器外的电脑（如 10.80.x.x 网段）检查不到更新。局域网不可达时改从 GitHub Release 获取，之前这个备用来源一直失败。检查失败后 1 小时重试，不再等 24 小时。

## 修复

- **点击表情后崩溃**：在会话中点击“表情”按钮，应用直接退出。现在表情面板可以正常打开和插入。
- **对方离线时弹出错误**：正在对话的设备离线或断开时，页面顶部出现红色“连接已中断”错误条，需要手动关闭。现在只把状态改为“连接已断开”，会话和未完成的消息照常显示断开。发文字时因网络断开或超时失败，也只在该条消息上显示失败，不再出现错误条。

## 兼容性

- 协议版本不变（v6），与 macOS 0.5.0 及以上版本可使用全部功能。
- 只提供 EXE 安装包。
- 1.3.1 及更早版本只信任 `192.168.50.229`：二级路由器下的电脑可以照常应用内升级；其他网段的电脑需要手动安装一次 1.3.2，之后即可自动更新。
