# Windows 文件接收确认

本功能为同一条已建立的 v3 会话加入逐个文件/图片的接收方确认。发送端先发送已加密的文件元数据，接收端在聊天卡片展示来源、名称、类型和大小；用户选择“接收”后才创建临时文件并开始写入，选择“拒绝”则返回加密拒绝决定且不创建文件。等待确认最多 2 分钟；超时、断线或本地存储错误都不会开始数据传输，并清理待处理状态。拒绝、超时和接收目录不可用后关闭当前连接。

因 v3 会话采用单读循环，等待文件决定期间该会话暂不处理文字或其他文件记录。双方应同时更新到支持此确认语义的版本。旧版本会在文件元数据后立即返回接受决定，因此无法提供旧版接收端的确认 UI；新版接收端拒绝后关闭连接，以避免旧发送端基于其原行为继续写数据。

聊天记录将拒收和超时分别保留为拒收/失败状态，对方拒绝的发送端卡片可手动重试。已接收文件仍使用临时文件、字节数与 SHA-256 校验后原子提交。此功能不改变 v3 文件数据使用 AES-256-GCM 加密的机制。

构建和双机验收应在 Parallels 的 Windows 环境执行，至少覆盖：接收、拒绝、两分钟确认超时、确认期间取消连接、等待确认时消息发送队列行为、接收目录不可写、零字节文件，以及拒收后继续发送文字/其他文件。
