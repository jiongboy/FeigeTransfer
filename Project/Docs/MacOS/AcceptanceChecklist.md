## 两台实体 Mac

- [ ] 启动时钥匙串签名授权；选择“始终允许”后反复连接；取消授权可重试；一端授权较慢不再触发 15 秒超时。
- [ ] 两端安装 0.3.3 预览包；首次局域网授权允许/拒绝后均有明确状态。
- [ ] 打开应用后互相发现；只询问接收方是否同意，发起方无需额外确认。
- [ ] 使用发现和手动 IP/端口连接，同意后直接双向传输，无配对码、短码或逐文件确认。
- [ ] 拒绝连接、取消、断网、错误 ID/偏移/摘要均不产生伪成功。
- [ ] 同名文件保留；文件 SHA-256 一致；重启后记录、名称、接收目录恢复。
- [ ] 一次同意可传多批文件、超过 100 MB 的大文件和空文件；中途失败只重试剩余文件，重连才重新询问。
- [ ] 首次设置、设备名称键盘编辑、偏好设置重开、连接同意窗口与进度显示正常。
- [ ] 关闭主窗口后点击 Dock 重开，最小化恢复，⌘1 重开；设置窗口打开时也能恢复主窗口。
- [ ] 双机文字聊天、中文输入法、图片拖入、缩略图预览、原图打开、文件访达定位；切换设备不误发消息。
- [ ] 磁盘不足、写入权限撤销、VPN、多网卡、访客 Wi-Fi 隔离、休眠恢复。
- [ ] 偏好设置各卡片操作：改名重新广播、更改接收目录、启用/关闭/测试通知、清空记录、打开数据目录、恢复隐藏会话、退出应用。
- [ ] 提示条：首次连接、首次收发、通知邀请（接受与跳过均不再重复）、关闭窗口后台提示只出现一次、授权失败提示。
- [ ] 网络变化（切换 Wi-Fi、插拔网线、VPN 启停）后自动重新发现，已建立连接与监听端口不中断。
- [ ] 内置表情面板、草稿在切换设备与重启后保留。
- [x] 应用更新基本链路：在本机 macOS 27 arm64 客户端完成 build 9 → build 10 的签名清单检查、下载、大小/SHA-256 校验、代码签名验证、原子替换、自动重启和新版本确认；清单与包从 Mac mini LAN 服务获取。
- [x] 更新完成提示条关闭：从 build 10 更新到 build 11 后，使用界面关闭按钮关闭成功提示，提示条立即消失。
- [ ] 应用更新边界场景：跳过此版本、自动检查 24 小时间隔、收发中等待安装、签名/摘要错误拒绝、应用位置不可写。

本轮使用 AppleScript 驱动真实应用设置界面；Mac mini 为 macOS 12.7.6 Intel，低于应用要求的 macOS 13.0，因此只承担更新服务，客户端升级验收在本机完成。完整原生界面矩阵仍待人工验收。
