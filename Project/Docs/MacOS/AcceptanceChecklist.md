## 两台实体 Mac

- [ ] 启动时钥匙串签名授权；选择“始终允许”后反复连接；取消授权可重试；一端授权较慢不再触发 15 秒超时。
- [ ] 两端安装 0.3.3 预览包；首次局域网授权允许/拒绝后均有明确状态。
- [ ] 打开应用后互相发现；只询问接收方是否同意，发起方无需额外确认。
- [ ] 使用发现和手动 IP/端口连接，同意后直接双向传输，无配对码、短码或逐文件确认。
- [ ] 拒绝连接、取消、断网、错误 ID/偏移/摘要均不产生伪成功。
- [ ] 同名文件保留；文件 SHA-256 一致；重启后记录、名称、接收目录恢复。
- [ ] 一次同意可传多批文件、超过 100 MB 的大文件和空文件；中途失败只重试剩余文件，重连才重新询问。
- [ ] 首次设置、设备名称键盘编辑、偏好设置重开、连接同意窗口与进度显示正常。
- [ ] 关闭主窗口后点击 Dock 重开，最小化恢复，⌘1 重开；设置窗口打开时也能恢复主窗口。
- [ ] 双机文字聊天、中文输入法、图片拖入、缩略图预览、原图打开、文件访达定位；切换设备不误发消息。
- [ ] 磁盘不足、写入权限撤销、VPN、多网卡、访客 Wi-Fi 隔离、休眠恢复。

当前没有界面自动化权限，因此这里的真实窗口操作尚未自动验收。
