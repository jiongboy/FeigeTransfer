# macOS 0.5.1 发布说明

状态：**已发布**（2026-11-03，build 17，已公证）。含文件大小与 SHA-256 的定稿在 `Release/MacOS/0.5.1/ReleaseNotes-0.5.1.md`，公开页面为 [GitHub macos-v0.5.1](https://github.com/jiongboy/FeigeTransfer/releases/tag/macos-v0.5.1)。逐轮实现与验证见 [macOS 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 改进

- **选择群成员**：创建群聊和群主添加成员改用同一个双栏弹窗：左侧搜索并勾选设备，未连接或版本过低的设备置灰并写明原因；右侧显示已选设备和剩余名额。一次选中的设备作为同一次成员变更提交。
- **其他网段更好填**：
  - 可以只写前三段，如 `192.168.60`，保存时自动补成 `192.168.60.0/24`。
  - 新增“添加常用网段”菜单，列出常见路由器的默认网段并注明品牌，点选后填入输入框，保存后才开始探测。
- **公司网段自动探测**：本机地址在 `10.80.x.x` 时，自动探测 `10.80.1.0/24` 和 `10.80.10.0/24`，无需填写；离开公司网络即停止。设置页会提示当前是否在自动探测。

## 兼容性

- 最低系统版本 macOS 13.0；协议版本不变（v6），与 Windows 1.3.0 及以上版本可使用全部功能。
