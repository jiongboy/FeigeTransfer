# macOS 0.5.3 发布说明

状态：**已发布**（2026-11-04，build 19，已公证）。公开页面为 [GitHub macos-v0.5.3](https://github.com/jiongboy/FeigeTransfer/releases/tag/macos-v0.5.3)。逐轮实现与验证见 [macOS 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 改进

- **连接请求只需同意一次**：同意后对方自动成为常驻联系人，之后这台设备再连接无需确认，上线时自动连接；可在设置的常驻联系人中移除。接收文件仍需逐次确认。
- **发现路由器后面的设备**：对方在另一个子网（如二级路由器下）时，原来常常发现不了。现在会主动探测对方地址，能发现时即可连接。
- **断线后自动重连**：对方意外断开（崩溃、网络波动）后，本机会在一段时间内自动重拨；手动断开不会重连。

## 修复

- **自动重连失败弹框**：信任设备自动重连、群组自动连接或对方发起的握手超时会弹出“局域网传输超时。”。现在只有手动点“连接”或“重新连接”失败才提示，其他情况只更新连接状态；发文字因断开失败也不再弹框。

## 兼容性

- 最低系统版本 macOS 13.0；协议版本不变（v6），与 Windows 1.3.0 及以上版本可使用全部功能。
- 应用内更新来源不变（`192.168.50.229:8080`）。
