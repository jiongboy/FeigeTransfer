# macOS 0.5.0 发布说明（草稿）

状态：**草稿，尚未打包**。正式打包时复制到 `Release/MacOS/0.5.0/`，并补上文件大小与 SHA-256。逐轮实现与验证见 [macOS 开发日志](DevelopmentLog.md)，跨平台摘要见[更新日志](../Public/UpdateLog.md)。

## 新功能

- **新手引导与头像**：首次启动可选择 10 个内置头像，或跳过。
- **群成员面板**：在群聊里查看成员、角色与在线状态，可搜索。
- **跨网段**：可在设置中添加其他网段的探测目标。
- **未读与通知**：会话列表显示未读数，Dock 角标与系统通知提示新消息。
- **常驻联系人**：自动同意连接并在断线后自动重连；文件仍需逐次确认。
- **文件夹与断点续传（协议 v6）**：整个文件夹只确认一次；中断后从断点继续。
- **离线待发**：对方不在线时先排队，连接后按顺序发送。
- **会话合并**：右键“合并到其他会话…”，合并同一台设备的两段会话。
- **附近设备去重**：已有会话的设备不再重复显示。
- **身份保持**：卸载重装或删除资料目录后沿用原身份。

## 兼容性

- 最低系统版本 macOS 13.0。
- 与 Windows 1.3.0 及以上版本可使用全部功能；与旧版本互通时回退到双方都支持的协议。
